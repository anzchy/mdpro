## What to build

The shared MIG-001 corpus modules run in a browser as well as in Node, with every export and every corpus result unchanged.

- The recipe and metadata-guard SHA-256 checks use a synchronous SHA-256 that needs no Node built-in (a pure implementation in the corpus support; no new dependency).
- The negatives helper uses `TextEncoder` and `Uint8Array` in place of `Buffer`.
- The runner's environment comes from its existing `options.env`; no module reads `process` at import time.
- No corpus case, manifest, baseline, comparator rule or driver behaviour changes.
