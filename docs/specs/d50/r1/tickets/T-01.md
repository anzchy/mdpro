## What to build

On Windows, Toggle Sidebar's default binding becomes **Ctrl+Shift+F**, and **Ctrl+Shift+L** stays as a secondary binding, so
both chords toggle the sidebar. The View menu shows Ctrl+Shift+F. Settings → Keyboard Shortcuts lists it as the default, and
"Reset to default" restores it. A Windows config on defaults version 1 that still holds the v1 default migrates to it. A
chord the user chose is kept. macOS (⌘⇧L) and Linux (Ctrl+Shift+L) do not change, and the defaults version stays 2. The
command table remains the single source: the generated menu layout, the applied shortcuts and Settings all follow it
(rule 41). The keyboard shortcuts guide, the menu plan's v2 defaults table, the feature ledger and `CHANGELOG.md` change in
the same PR.

## Acceptance criteria

- [ ] AC-1 (unit, command table): the v2 bindings for Toggle Sidebar resolve as follows.
  - Windows: primary Ctrl+Shift+F, secondary Ctrl+Shift+L.
  - macOS: ⌘⇧L, with no new secondary.
  - Linux: Ctrl+Shift+L.
  - v1 is unchanged on every platform.
  - The binding-conflict laws hold: Ctrl+Shift+F is no other Windows action's default.
  - The generated menu layout is fresh.
- [ ] AC-2 (unit, keydown dispatch): on Windows v2 defaults, a Ctrl+Shift+F keydown and a Ctrl+Shift+L keydown each
  trigger `view.toggle_sidebar` exactly once and log `ui.shortcut.trigger` with the chord pressed.
  - Neither chord fires any other action.
  - After the primary is rebound, the secondary still works.
- [ ] AC-3 (unit, migration):
  - A Windows v1 config holding the v1 default moves to Ctrl+Shift+F.
  - A custom value is kept.
  - A v2-stamped Ctrl+Shift+L is kept.
  - "Reset to default" yields Ctrl+Shift+F.
- [ ] AC-4 (unit): the Windows View menu's Toggle Sidebar accelerator and the applied-shortcuts result both read
  Ctrl+Shift+F. Rule 41's audit finds no hardcoded sidebar accelerator left behind.
- [ ] AC-5 (docs): these all match the table:
  - the guide's Toggle Sidebar row, split by platform;
  - the menu plan's v2 defaults table;
  - the feature-ledger row;
  - a `CHANGELOG.md` Unreleased line.

  `pnpm ledger:check` passes.
