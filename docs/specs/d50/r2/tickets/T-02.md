## What to build

D50 is proved on the real Windows PC, `win-desktop`. The D50 device card is rewritten to the spec's device steps, then run
in the shared W036 rerun, on the same locked build as the driver fix. A PASS lets the D50 sequencing row close and the
0.3.6 release notes call it fixed.

A *real press* is a keystroke sent through the Windows device driver's real-input route (`ui.sh` `chord`) after a real
`clickat` sets focus. It is not a page (CDP) event, and not a key pressed by hand. An *interactive-desktop probe* runs in
the driver's scheduled task in the user's desktop session, since over SSH `RegisterHotKey` fails with 1459. The live
config on win-desktop is already v2-stamped with Ctrl+Shift+L, and correct code keeps that value. So the run starts from
configs derived from a snapshot, and restores the snapshot afterwards.

## Acceptance criteria

- [ ] AC-1 (device, setup): these are all recorded before any press.
  - The build identity (SHA-256 and the `app.ready` `releaseId`) matches the locked rerun build.
  - With mdpro closed, the user's `.mdpro` folder is snapshotted and the hashes are recorded.
  - Config **A** is the snapshot, v2-stamped, with `viewToggleSidebar` removed. Config **B** is v1-stamped, with
    `viewToggleSidebar` holding `Cmd+Shift+L`. Each launch records its stamp and stored sidebar value.
  - The target window's HKL and active input method are recorded (the default is WeType). Windows' input-language
    hotkeys are read, and none is Ctrl+Shift+1.
- [ ] AC-2 (device, interactive-desktop probe, mdpro closed):
  - `RegisterHotKey` for Ctrl+Shift+1 returns true, and `UnregisterHotKey` follows at once.
  - The result for Ctrl+Shift+L is recorded. On this PC it is expected to be lastError 1409.
- [ ] AC-3 (device, config A): a real Ctrl+Shift+1 press toggles the sidebar exactly once. `mdpro.log` shows one
  `ui.shortcut.trigger` with `view.toggle_sidebar` and `Cmd+Shift+1`, no other action runs, and the document bytes do not
  change. This holds in each of:
  - WYSIWYG, editor focused;
  - Source, editor focused;
  - a non-editor element focused.

  The View menu shows Ctrl+Shift+1. Real Ctrl+Shift+N, on the same route in the same run, passes as the card's control.
- [ ] AC-4 (device, config A): Ctrl+Shift+L matches its probe result.
  - If the probe returned 1409, a real press logs no trigger and the sidebar does not change. AC-3's presses and the
    Ctrl+Shift+N control are its passing same-route controls.
  - If the probe succeeded, a real press triggers once and logs `Cmd+Shift+L`.
- [ ] AC-5 (device, config B): after one launch, the config is stamped 2 and `viewToggleSidebar` holds `Cmd+Shift+1`. One
  real Ctrl+Shift+1 press toggles the sidebar once.
- [ ] AC-6: with mdpro closed, the snapshot is restored, and its hashes match those recorded in AC-1.
