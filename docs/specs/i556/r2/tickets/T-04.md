## What to build

The landing command's only override: one or more exception ids. Each lets the landing pass one failing check, and only
when the audit log's Gate exceptions section has a row with that id that meets all of these:
- its Closed cell is empty or `open`;
- its PR cell is this PR (`#<n>`), or `any` with an open `until <condition>` scope;
- a `this landing only` scope names the landing SHA;
- its Gate waived cell starts with a check token from `verifier | auditor:gpt | auditor:opus | ci-gate | device:<AC>`,
  then `:`, and that token is a failing check;
- its Ruling cell quotes the user in 「…」 or “…”.

A **post-cap row** has the check token `auditor:<name>` and the scope `post-cap <pre-ruling sha40> → <landing sha40>`.
It records an ADR-0129 decision 6 or ADR-0143 decision 3 or 4 ruling. It lets the named auditor's last report end at
the pre-ruling head, while the other auditor's confirm at the landing SHA must still be clear.

The grammar covers new rows only. Old rows stay as written and match nothing. A waived auditor or device AC counts only
this way. No other bypass flag exists.

## Acceptance criteria

- [ ] A failing check with a valid matching exception lands, and the output names each exception used. Two exceptions
      covering two failing checks land.
- [ ] An exception id with no row is refused.
- [ ] A row for another PR, for another SHA under `this landing only`, or with a Closed value is refused.
- [ ] A row without quoted user words is refused.
- [ ] A row whose check token differs from the failing check is refused.
- [ ] An open `until` row with PR `any` matches a PR that fails that check.
- [ ] A waived auditor: a post-cap row for `auditor:opus` lands with opus's last report at the pre-ruling head and
      gpt's clear confirm at the SHA. The same evidence without the row is refused, naming `auditor:opus`.
- [ ] A waived device AC: a `device:<AC>` row lands with that AC's report missing. The same without the row is refused.
- [ ] An old-format row (fixture copy of G551-1) matches nothing.
- [ ] Without an exception, every failing check still refuses (no default bypass).
- [ ] Proved at the landing-command process seam, with a fixture audit log.
