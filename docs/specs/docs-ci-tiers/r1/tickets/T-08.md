#594. Ticket **T-08**. High tier, gate-sensitive.

## What to build

A `windows-latest` job runs `cargo test` and `pnpm build` on PRs that touch Rust or the Cargo files. It stays outside `ci-gate`. Ten consecutive green runs allow its promotion, by its own later decision-log entry. A red on a PR whose base was green goes into the audit request as a Medium and resets the count. Installer builds on PRs are not included. The count and the Medium procedure are written into the delegator skill.

Spec: DCT-r1-D14; stories 30–32.

## Acceptance criteria

- [ ] AC-1 (unit, seam 3): the Windows job runs on Rust or Cargo PRs, runs `cargo test` and `pnpm build`, and is not in `ci-gate`'s needs.
- [ ] AC-2 (unit, seam 3): no installer build runs on PRs.
- [ ] AC-3: the delegator skill names the ten-green count, the reset, and the Medium in the audit request.
