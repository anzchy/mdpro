## Parent

#594. Ticket **T-04**. High tier, gate-sensitive.

## What to build

A cheap, non-blocking `prose-lint` job: codespell, markdownlint-cli2 and an offline repo script for relative links and anchors, on changed files only. It runs on PRs and on a push-to-`master` trigger, and is never in `ci-gate`'s needs. Tool versions are pinned inside the job; `package.json` is unchanged; one repo script runs the same versions locally. The markdownlint config turns off the rules that fight existing docs (line length, CJK spacing). A red after a push to `master` is fixed in the delegator's next docs commit, with no D row.

Spec: DCT-r1-D7; stories 15–19.

## Acceptance criteria

- [ ] AC-1 (unit): the links-and-anchors script reports a broken relative link and a missing anchor (including a CJK heading anchor), passes a good one, and makes no network request.
- [ ] AC-2 (unit, seam 3): the workflow runs `prose-lint` on PRs and on push to `master`, on changed Markdown files only, and `prose-lint` is not in `ci-gate`'s needs.
- [ ] AC-3 (unit, seam 3): each tool's version is pinned in the job and the local script uses the same versions; `package.json` and the lockfile are unchanged.
- [ ] AC-4: the markdownlint config disables line length and CJK spacing.

## Blocked by
