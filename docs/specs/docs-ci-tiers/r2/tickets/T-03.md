## What to build

The landing command's docs-only mode accepts only `prose` paths, from the T-01 classifier. When a commit touches a prose Gate input, the command first runs that input's readers (`doc-policy`'s config over those tests, without coverage, under `scripts/heavy-lock.sh --guard-only`, plus the gate scripts that read it, with `journeys:check --base origin/master`). It refuses the push on any failure, or on failing to run them.

The Claude delegator lands through the same command. The role guard gains a `delegator` branch that refuses every other spelling of a `master` update, and `delegator-route.sh` blocks dispatch on the Claude route unless `MDPRO_ROLE=delegator`.

The "docs-only landing route" entry lands with the rewritten rule 70 § Commits item 2, the "Only the delegator lands" paragraph, the delegator skill's landing steps, and CLAUDE.md § User questions' how-to line (a direct commit puts a new how-to under `docs/knowledge/`; a `docs/guide/` edit goes through a PR).

## Acceptance criteria

- [ ] AC-1 (unit, seam 1): docs-only landing and the CI scope step give the same answer for every path in T-01's table. Docs-only refuses any `policy` or `code` path, and still refuses the two pinned audit files.
- [ ] AC-2 (unit, seam 3): on a fixture repo, docs-only landing of a prose Gate input:
  - runs the input's readers;
  - pushes when they pass;
  - refuses when one fails;
  - refuses when one cannot run.

  A prose commit with no Gate input runs nothing extra.
- [ ] AC-3 (unit, seam 3): with `MDPRO_ROLE=delegator`, the role guard refuses each of:
  - `git push origin master`, `HEAD:master` and `<sha>:refs/heads/master`;
  - a bare `git push` on `master`;
  - `--all` and `--mirror`;
  - `git -C <dir> push … master`;
  - `gh api … git/refs/heads/master`.

  It allows the landing command, `--force-with-lease=<pr-branch>:<old>` and a push to `retro/*`. Other roles are unchanged.
- [ ] AC-4 (unit, seam 3): `delegator-route.sh` blocks dispatch on the Claude route when `MDPRO_ROLE` is not `delegator`, and passes when it is.
- [ ] AC-5: the entry and the four text changes land in one commit, and the entry is indexed. Both auditors plan-reviewed it.
