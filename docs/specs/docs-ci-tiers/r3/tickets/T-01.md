## Parent

#594 (spec r3). Ticket **T-01** (issue #595, revised). High tier, gate-sensitive.

## What to build

One classifier gives each path, with its git mode, a change scope (`prose`, `policy` or `code`) and a Gate-input flag with that input's readers (DCT-r2-D1–D4). The Gate-input scan (D5) ships in the same ticket, so prose widens only for paths the scan proves nothing reads. The scan's inventory is checked against D7's list.

The CI scope step uses it and emits `scope`, `doc_policy`, `rust` and `slow`. In this ticket `ci-gate` still runs full CI for `policy`, and for `prose` with a Gate input: no new skip exists until T-02. Prose with no Gate input skips `frontend` and `rust-test`, as prose does today.

The "change scopes" decision-log entry lands in the same commit as a new `70-multi-session-coordination.md#change-scopes` subsection holding the current text. ADR-0095 gains its dated "Current text: …#change-scopes; folded and changed by …" line for decision 2.

Spec: DCT-r2-D1–D5, D7, D20 (change-scopes entry); stories 1, 13, 14, 16, 17, 37.

## Acceptance criteria

- [ ] AC-1 (unit, seam 1): path and mode in, scope and flag out, for a table covering every D2/D3/D4 class: `docs/agents/decisions/**`, `docs/specs/**`, `GLOSSARY.md`, `TODOS.md`, root `DESIGN.md`, `design/**/*.md`, `design/**/*.html`, `.claude/settings.json`, `.codex/rules/*.rules`, `.codex/agents/*.toml`, a symlink, a submodule, an executable `.md`, and an unknown root file.
- [ ] AC-2 (unit, seam 1): a range's scope is the most demanding answer across its paths; an empty or unreadable range is `code`.
- [ ] AC-3 (unit, seam 2): the scan runs over the real sources and passes on the committed tree, and its inventory equals D7's prose Gate inputs (`docs/test/journey-runs/` as a directory): none missing and none extra.
- [ ] AC-4 (unit, seam 2): on fixtures, the scan:
  - turns a directory literal into a Gate input for a new file under it;
  - follows a constant exported from a helper to every test that imports it;
  - narrows a directory by a `gate-inputs:` annotation;
  - ignores a literal in a comment;
  - makes nothing a Gate input from a `not-a-read:` literal (a classification prefix, an exclusion list, a path passed as data);
  - reports an unannotated `docs/` or `design/` whole-tree literal as an error;
  - reports a literal naming no path as an error.
- [ ] AC-5 (unit, seam 3): the scope step emits `scope`, `doc_policy`, `rust` and `slow`; `doc_policy` is true for `policy` and for `prose` with a Gate input, and an empty or unreadable range emits `code` with all three `true`. `ci-gate` treats `doc_policy=true`, like `code`.
- [ ] AC-6: the "change scopes" entry, the rule 70 `#change-scopes` subsection and ADR-0095's dated forward line land in one commit, and the decision-log README indexes the entry. Both auditors plan-reviewed the entry first.
