## What to build

A `prose-lint.yml` workflow on `pull_request` and on push to `master`. It is never part of `ci-gate`.

It runs codespell, markdownlint-cli2 (line length and CJK spacing off) and an offline repo script for relative links and anchors, on changed Markdown files only.

- **Versions** are pinned in the job. One local script runs the same versions, and `package.json` is unchanged.
- **A red after a push** is fixed in the next docs commit, with no D row.
- **The record.** The `prose-lint` decision-log entry (not gate-sensitive) rides this PR.

Spec: DCT-r2-D13; stories 18–21.
