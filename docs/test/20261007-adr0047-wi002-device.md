# ADR-0047 WI-002 真机验收记录（2026-10-07）

计划：[`docs/plans/20261002-plan-agent-control-channel.md`](../plans/20261002-plan-agent-control-channel.md) § WI-002。
执行方：主会话用 `/gui-acceptance`（computer use）驱动，Finder 双击和 5c 的 HTTP 探针由人执行（本机权限不允许会话发 localhost 请求）。

## 0. 测量条件

| 项 | 值 |
|---|---|
| 机器 | Apple Silicon，macOS 26.3.1 (a)，build 25D771280a |
| 被测构建 | `pnpm control:build --profile verify`，`src-tauri/target/verify/release/bundle/macos/mdpro-verify.app`，由 `e36c63a` 构建，工作区干净；清单 `buildId` `25de09dd…`，`features: []` |
| 日常 app | `/Applications/mdpro.app` v0.3.0（`com.mdpro.app`） |
| 运行目录 | 由临时脚本按启动器（WI-003）的约定建：父目录与运行目录 0700，`launch.json` 带随机数，四个变量都取 realpath，`HOME` = `CFFIXED_USER_HOME` = 运行目录 |
| 旁证清单 | 对真实 `~/.mdpro`、`~/Library/Application Support/mdpro` 和四个 MCP 客户端配置取 `stat` 元数据（路径、大小、mtime），不读内容 |

**测试脚手架的教训**：第一次运行预置了只含 `{"mcp":{"serverEnabled":true}}` 的 `config.json`。`UserPreferences` 有不带 `serde(default)` 的必填字段，整份解析失败，设置页全部显示 “Failed to load …”。这是脚手架错误，不是 WI-002 的缺陷；之后的运行不预置偏好，app 首启自己写全量默认值。WI-003 的启动器写偏好夹具时必须写**完整**的一份。附带观察：偏好文件损坏时 app 不回落到默认值，只在每个设置页报错（既有行为，与本 WI 无关）。
