# Card D255-windows: Windows chords for the four D255 implementation batches

**Controlling AC** ([D255](../../plans/20260912-frontend-backend-sequencing-order.md#d255) and [menu plan § 5.8](../../plans/20261015-plan-menu-reorganisation.md#58-d255-what-each-no-effect-action-becomes), quoted):

> **D255's builds, from § 5.8 as D255-WI-1 left it**, in four batches: **a** Source commands (marks, fences, lists, Quote, Math, Select Line, Delete Word); **b** WYSIWYG commands (heading level, Select Word, Select Line, Clear Format, Image) and Underline in both modes (§ 5.8 row 6, user decision 2026-10-16: 「Build an underline mark」); **c** WYSIWYG find and replace from the chosen prototype; **d** file and app (Save As, Switch Documents, off-Mac full screen under U7).

> Per row: the command through the menu and through its key, in each mode the row enables, runs once and is one undo step; disabled modes stay refused with a toast; Save As writes the new path and leaves the old file untouched, cancel writes nothing; Image in an untitled document shows the paste toast and inserts nothing, and a cancelled picker inserts nothing; Underline, as serializer fidelity tests: `<u>x</u>` round-trips byte-identical through WYSIWYG, a document with no underline stays byte-identical on save (the D204 / D209 class), and export keeps `<u>` through the sanitizer (`services/markdown.rs:426`); Switch Documents follows MRU order with one tab and with none; find / replace: next and previous wrap, replace and replace-all are each one undo step, Escape closes and returns focus.

The quote's repository-relative sanitizer shorthand resolves on current master to `src-tauri/src/services/markdown.rs:426`.

This card covers only the Windows real-key and AltGr-interplay portion. It does not repeat serializer, export, macOS, or unit-only fidelity claims.

- Use the current-master `build-windows.yml` development artifact and record workflow `head_sha`, hashes, and `app.ready.releaseId == <version>-dev@<head_sha>`. Record display scale (expected 270%) and maximize to about 1120 CSS px or wider.

Use labelled real `ui.sh` chords for OS-level key proof and CDP only to set selections/read effects after launch.
- Run with the applied shortcut version 2 defaults. If the configuration contains custom or suppressed keys, restore defaults for the run and restore the original snapshot afterward.

## Failure condition

Fail if a listed Windows chord runs zero or twice, runs in a disabled mode, a document mutation cannot be undone as one step, a selection-only command changes document bytes, Save As touches the old file or writes on cancel, a recorded Save As output remains after cleanup, the final directory listing differs from its snapshot, cleanup would need to delete an unrecorded addition, MRU/fullscreen effects disagree with their logs, or an AltGr character becomes a command. A failure requires a passing same-route chord in the same run.
