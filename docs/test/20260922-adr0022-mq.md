## Verdict

- **MQ-1 (Source entry), MQ-2, MQ-3, MQ-4: DONE.**
- **MQ-1 (WYSIWYG entry): the log part is DONE**: 1 degrade, then 1 withheld, in that order. **The "exactly 2 toasts" count is NOT VERIFIED**, because the single-slot, 3 s toast cannot be sampled by screenshot.

Logging was left **ON** (`{"enabled": true, "level": "info"}`). `server.port` and
`server.token` were not touched.

## Observations (not MQ failures)

- **⌘⌥↓ in a withheld document adds a second cursor.** The app's table gate returns early
  as designed, and the text is unchanged. But CodeMirror's own default binding for
  ⌘⌥↓ (add cursor below) still fires, so the result is two cursors. The spec's check,
  "leaves the text unchanged", holds. This is a UX note: in small documents the table
  shortcut shadows that binding; in withheld documents it does not.
- **The `source_tables_withheld` line carries no `documentId`.** In this pass the lines
  were matched to documents only by their order next to `file.open` / `tab.open`. With
  two large documents open at once, the log cannot tell which document was withheld.
  Adding `documentId` to the context would make "exactly 1 line per document" countable
  with `grep` alone.
- **A tab click near the right end of the inactive tab's label did not switch tabs**
  (2 attempts, and no `tab.switch` was logged). A click on the label text did switch.
  The tester's pointer placement cannot be ruled out, so this is not recorded as a defect.
- While the tab was dirty, the large document autosaved every 30 s: `file.write` of
  9,961,503 B, to the file itself.
