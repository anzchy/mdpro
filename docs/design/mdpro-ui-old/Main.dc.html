# Typora Parity — Phase 1
 
Phase 1 wires math, footnotes, autolinks and emoji on
the **canonical Rust render surface** — Preview and
HTML export.
 
## Scope
 
- Inline math `$E = mc^2$` and display math
- Footnotes `[^1]` with backrefs
- GFM autolinks and `:emoji:` shortcodes
 
> Milkdown WYSIWYG does not typeset math yet —
> accepted Phase 1 behaviour, not a bug.
 
## Render pipeline
 
```rust
render_markdown(src)
.and_then(sanitize_html)
```
 
| Surface | Math | Footnotes |
|---------|------|-----------|
| Preview | yes | yes |
| Export | yes | yes |
