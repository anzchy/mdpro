What to fix here
1 · Style the row label. globals.css styles .settings-row-label strong and .settings-row-description but never h4 or p. Two selectors fix eight panels.
2 · One boolean control. .toggle-switch already exists and is fully built. Five panels reach past it for a raw checkbox.
3 · The nav rail is emoji. ⚙️ ✏️ 📝 🖼️ 🔗 📤 🎨 ⌨️ 🔧 ℹ️ — vendor-drawn, full-colour, differently weighted, and they shift with the OS font. Same root cause as the missing icon set on the Component inventory board.
4 · The running badge is hardcoded. #dcfce7 on #16a34a with no dark override — flip this artboard to dark and it stays mint green.
5 · No Save, no Cancel. Every panel writes through on change (debounced 500ms for text, immediate for booleans, rolled back silently on failure). The footer's lone Close button reads like an unsaved-changes prompt that never comes.
