Sidebar toggle — prototype

Click the panel button to hide or show the sidebar. Pattern from VMark (xiaolai/vmark @ 7916d41): while the sidebar is open, a close button sits at the right of the sidebar footer; while it is closed, an open button appears at the window's bottom-left. Switch the window width to see the sidebar keep the same 220px at full, ½ and ⅓ screen (issue #416).

Windows fixes

The sidebar keeps its width at every window size. Hiding it is the user's choice, made with the button at the bottom-left or ⌘⇧L — never a side effect of snapping the window to half the screen.

While the sidebar is hidden, the main bar's left padding clears the traffic lights, as DESIGN.md § Main bar requires.

What this proposes

  • A (VMark): close button at the right of the sidebar footer while open; open button as the first item of the bottom tab bar while closed. Clicking it moves the button about 200px, so undoing a click means finding it again.
  • B: one button that never moves, first in the bottom tab bar; its icon and label swap (Hide ↔ Show), so a second click undoes the first in place.
  • Icon button per DESIGN.md: 24px, transparent, muted, --color-hover on hover, --color-focus-ring outline. Icons redrawn to mdpro's 1.75-stroke set (VMark uses lucide at 2px, 14px).
  • No width animation and no auto-collapse: the sidebar is 220px at full, ½ and ⅓ width (#416). VMark has neither either.
  • Shortcut stays ⌘⇧L (VMark: ⌃⇧0; Codex app: ⌘B).
