mdpro Architecture

A local Markdown editor for macOS combining Typora's WYSIWYG experience with modern design. Built with Tauri 2.0 (Rust backend + React frontend).

v0.1.5 macOS 13+ Apple Silicon

High-Level Architecture

R

Frontend (src/)

  • React 19 + TypeScript 5.8
  • CodeMirror 6 (Source Editor)
  • Milkdown 7.18 (WYSIWYG)
  • Zustand 4 (State)
T

Tauri IPC Bridge

invoke() →
Commands
file.open, file.save, export.html
← emit()
Events
menu:action, file:changed, theme:changed
Rs

Backend (src-tauri/)

  • Rust 2021 Edition
  • Tauri 2.0 Runtime
  • pulldown-cmark (Markdown)
  • notify (File Watcher)

Project Structure

FRONTEND src/ 
src/
├── App.tsx              # Root component
├── components/
│   ├── Editor/          # CodeMirror + Milkdown
│   ├── Preview/         # Markdown preview
│   ├── Sidebar/         # Document tabs
│   └── common/          # Dialogs, toasts
├── hooks/               # useDocument, useMenuEvents
├── plugins/             # Editor plugin system
├── stores/              # Zustand stores
├── services/            # Tauri IPC wrappers
└── types/               # TypeScript definitions
BACKEND src-tauri/ 
src-tauri/src/
├── main.rs              # Entry point
├── lib.rs               # Module exports
├── menu.rs              # Native macOS menu
├── launch.rs            # File associations
├── commands/            # IPC handlers
│   ├── file.rs          # File operations
│   ├── export.rs        # HTML export
│   └── preferences.rs   # Settings
├── services/            # Business logic
└── models/              # Data structures
