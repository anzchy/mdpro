Frontend Architecture

React 19 + TypeScript 5.8 + CodeMirror 6 + Milkdown 7.18

Component Hierarchy

App.tsx — Root orchestrator, manages lifecycle
TitleBar.tsx — Native macOS title bar
Sidebar.tsx — Document tabs
└─ FileItem.tsx — Individual tab
Editor Views — Based on viewMode
├─ SplitView.tsx (split mode)
│ ├─ Editor.tsx (CodeMirror)
│ └─ Preview.tsx
├─ Editor.tsx (editor-only mode)
├─ Preview.tsx (preview-only mode)
└─ MilkdownEditor.tsx (wysiwyg mode)
Dialogs — Modal overlays
├─ SettingsDialog.tsx
├─ EncodingDialog.tsx
├─ RecoveryDialog.tsx
├─ ReloadDialog.tsx
└─ ConfirmDialog.tsx

Component Details

EDITOR

Editor.tsx

CodeMirror 6 wrapper for source editing with Markdown extensions.

Key Features:
  • Markdown syntax highlighting
  • Line numbers and folding
  • Plugin system integration
  • Undo/redo tracking
Location: src/components/Editor/Editor.tsx
WYSIWYG

MilkdownEditor.tsx

Milkdown-based WYSIWYG editor with Typora-like experience.

Key Features:
  • Rich text editing
  • Inline markdown preview
  • Typora-style keyboard shortcuts
  • Plugin extension support
Location: src/components/Editor/MilkdownEditor.tsx
PREVIEW

Preview.tsx

Rendered Markdown preview with syntax highlighting.

Technologies:
  • marked (Markdown parsing)
  • DOMPurify (XSS protection)
  • highlight.js (code blocks)
  • Scroll sync with editor
Location: src/components/Preview/Preview.tsx
NAVIGATION

Sidebar.tsx

Document tab management and navigation.

Features:
  • Multi-document tabs
  • Modified indicator
  • Close/switch documents
  • Toggle visibility (⌘⇧B)
Location: src/components/Sidebar/Sidebar.tsx

Custom Hooks

Hook Purpose Key Methods
useDocument Document CRUD & file operations openDocument, saveActiveDocument, closeDocument
useEditor View mode & sidebar state setViewMode, cycleViewMode, toggleSidebar
useMenuEvents Listen to native menu actions Handles menu:action events from Rust
useFileWatcher External file change detection Triggers ReloadDialog on changes
useAutoSave Periodic draft saving Auto-saves every N seconds
useMilkdown Milkdown editor setup Editor initialization & plugins
useTheme Theme switching Light/dark/system mode
useScrollSync Scroll synchronization Sync editor & preview scroll
