File Open Flow

1
User Action Trigger

User clicks File → Open or presses ⌘O

menu.rs → emit("menu:action", { action: "file.open" })
2
Menu Event Handler Frontend

useMenuEvents hook catches the event

useMenuEvents.ts → listen("menu:action") → openDocumentFromDialog()
3
IPC Command Tauri IPC

Frontend invokes Rust command via Tauri

fileService.ts → invoke("open_file_dialog", { actionId })
4
Rust Handler Backend

Rust shows native file dialog, reads file, detects encoding

commands/file.rs → rfd::FileDialog → fs::read() → encoding::detect()
5
Store Update State

Document added to store, becomes active

documentStore → upsertDocument(doc) → setActiveDocumentId(doc.id)
6
File Watcher Backend

Backend starts watching file for external changes

services/file_watcher.rs → notify::watch(path)
✓
UI Render Frontend

Editor displays document content

Editor.tsx → CodeMirror renders doc.content

File Save Flow

1. User presses ⌘S or clicks Save
↓
2. useDocument.saveActiveDocument() called
↓
3. If no path → invoke("save_file_dialog")
↓
4. Rust writes content to disk
↓
5. Draft backup saved to ~/.mdpro/drafts/
↓
6. documentStore marks as not modified

Implementation

// useDocument.ts
const saveActiveDocument = async () => {
  const doc = getActiveDocument();
  if (!doc) return;

  const actionId = generateActionId();

  try {
    if (doc.path) {
      // Save to existing path
      await fileService.saveFile({
        documentId: doc.id,
        content: doc.content,
        path: doc.path,
        actionId,
      });
    } else {
      // Show save dialog
      const result = await fileService
        .saveFileDialog({
          documentId: doc.id,
          content: doc.content,
          suggestedName: 'Untitled.md',
          actionId,
        });
      if (result.path) {
        updateDocumentPath(doc.id, result.path);
      }
    }
    markDocumentSaved(doc.id);
  } catch (err) {
    showError('Failed to save');
  }
};

Structured Logging Flow

Event Logging Pattern

// Generate action ID for correlation
const actionId = loggingService.generateActionId();

// Log start
loggingService.logEventSync({
  level: 'info',
  event: 'file.open',
  status: 'start',
  actionId,
  context: { path },
});

try {
  const result = await openFile(path);

  // Log success
  loggingService.logEventSync({
    level: 'info',
    event: 'file.open',
    status: 'success',
    actionId,
    durationMs: elapsed,
  });
} catch (err) {
  // Log failure
  loggingService.logEventSync({
    level: 'error',
    event: 'file.open',
    status: 'fail',
    actionId,
    error: err.message,
  });
}
