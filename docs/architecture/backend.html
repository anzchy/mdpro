Command Handlers

FILE commands/file.rs
open_file(path, encoding, action_id)

Opens file, detects encoding, returns Document

open_file_dialog(action_id)

Shows native file picker, opens selected file

save_file(doc_id, content, path, action_id)

Saves content to path, creates draft backup

save_file_dialog(...)

Shows save dialog, saves with chosen name

close_document(doc_id, discard)

Closes document, optionally discards changes

reload_file(path)

Reloads file from disk

create_document()

Creates new untitled document

EXPORT commands/export.rs
render_markdown(content)

Converts Markdown to HTML fragment

export_html(markdown, title)

Generates complete HTML document

preview_html(markdown)

Returns preview-optimized HTML

DRAFT commands/draft.rs
save_draft(doc_id, path, content)

Saves auto-save draft

get_draft(doc_id)

Retrieves draft by document ID

list_drafts()

Lists all available drafts

recover_draft(draft_id)

Recovers draft content

cleanup_old_drafts(days)

Removes drafts older than N days

PREFS commands/preferences.rs
get_preferences()

Returns UserPreferences object

set_preferences(prefs)

Persists preferences to JSON file

get_system_theme()

Returns "light" or "dark"

save_window_state(geometry)

Saves window position/size

Business Logic Services

👁

file_watcher.rs

External file change detection

notify crate
Functionality
  • • Watches open document paths
  • • Detects external modifications
  • • Emits file:changed events
  • • Debounces rapid changes
Event Payload
{
  path: string,
  changeType: "modified" | "deleted"
}
🔤

encoding.rs

Character encoding detection

Detects file encoding (UTF-8, UTF-16, GBK, etc.) when opening files. Falls back to UTF-8 if detection fails.

📝

markdown.rs

Markdown to HTML rendering

pulldown-cmark

Uses pulldown-cmark for fast, spec-compliant Markdown parsing. Supports GFM extensions (tables, task lists, strikethrough).

📋

logger.rs

Structured JSONL logging

~/.mdpro/mdpro.log
Log Entry Structure
{
  timestamp: "ISO8601",
  level: "info" | "warn" | "error",
  event: "file.open",
  status: "start" | "success" | "fail",
  action_id: "uuid",
  context: { ... },
  duration_ms: 123,
  error: null | "message"
}
Event Naming
  • file.open, file.save, file.close
  • app.launch, app.ready, app.quit
  • window.open, window.close
  • tab.open, tab.switch, tab.close
  • ui.button.click, ui.menu.select

Data Models

Document

struct Document {
    id: String,
    path: Option<PathBuf>,
    content: String,
    encoding: String,
    is_modified: bool,
    created_at: DateTime,
    modified_at: DateTime,
}

Draft

struct Draft {
    id: String,
    document_id: String,
    original_path: Option<PathBuf>,
    content: String,
    saved_at: DateTime,
}

UserPreferences

struct UserPreferences {
    theme_mode: ThemeMode,
    auto_save_interval: u32,
    keyboard_shortcuts: KeyboardShortcuts,
    recent_files: Vec<String>,
    window_state: WindowState,
    default_view_mode: ViewMode,
}

LogEntry

struct LogEntryPayload {
    level: LogLevel,
    event: String,
    status: LogStatus,
    action_id: Option<String>,
    context: Option<Value>,
    duration_ms: Option<u64>,
    error: Option<String>,
}
