# User questions and answers

The questions **the user asked** an mdpro session, and what the session
answered, when the answer is still worth finding a week later. Answers given
in a session's chat get buried under its peer messages; this file is where the
user finds them again. It is an index for routing: the knowledge itself lives
in the ADR, rule, guide or row each entry points to. The rule that governs it
is in `CLAUDE.md` § "User questions and answers" (user decisions,
2026-10-14: 「目前我在本session和各个session直接问的问题的回答会被很多消息淹没掉，之后你单独维护一个md文档」;
「排除系统自带askuserquestion tool引发的，一定是user来问的，才记录」; 2026-10-20:
「也不是所有问题都要如实记录，问开发进度这个就不用记录了」 and
「Archive status rows, tag the rest (Recommended)」).

- **Only questions the user asked.** A question a session put to the user
  (AskUserQuestion, or a question in prose) is not recorded here; its answer
  lives in the ADR, row or rule it decided. Instructions and slash commands
  are not questions either.
- **Record five kinds**, written in the **Kind** column:
  - `Decision`: the answer led to a decision, or explains one;
  - `How-to`: how a tool, rule or subsystem works;
  - `Diagnosis`: the root cause of something surprising;
  - `Assessment`: a feasibility or trade-off judgment later planning cites;
  - `Correction`: an earlier claim turned out wrong.
- **Don't record:**
  - progress or status snapshots (「进度如何」, 「X 在做什么」, 「都通过了吗」, 「can PR N merge」).
    The timeline, the sequencing doc and the PR already hold that answer;
  - yes/no questions about the current state;
  - questions whose whole answer is a pointer to an existing file.

  A status question whose answer turned up an anomaly is recorded as a `Diagnosis` of that cause.
- **Topic** is one of this closed set. A new topic is added here first.
  - `roles`: sessions, herdr, delegation, coordination rules;
  - `tdd`: receipts, test lanes, coverage, the TDD process;
  - `audit`: audits, the landing gate, PR review;
  - `device`: real-device tests, the Mac mini, Windows;
  - `ci-release`: CI, release, versioning, the updater;
  - `save-file`: save, open, drafts, the watcher, encoding;
  - `editor-ui`: the editors, UI, design, shortcuts, menus;
  - `mcp`: the MCP server, its tools and confirm flow;
  - `settings`: preferences, logging settings;
  - `tooling`: repo scripts, hooks, skills, plugins, Codex config;
  - `git`: branches, worktrees, git operations;
  - `docs`: documentation, the ADR process, knowledge files.
- **The question is quoted verbatim; the answer is condensed** to what the
  session concluded (one to four sentences), with a pointer to the durable
  home of anything longer (a guide, ADR, row, report or commit).
- **Newest entry first.** Rows are not edited after commit; a corrected answer
  is a new `Correction` entry that names the one it corrects.
- **Status rows moved to the archive on 2026-10-20.** The one-off cleanup moved
  every progress and status row, verbatim, to
  [`user-question-and-answer-archive.md`](./user-question-and-answer-archive.md),
  and tagged the rest with Kind and Topic.
