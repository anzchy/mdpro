# User questions and answers

The questions **the user asked** an mdpro session, and what the session
answered. Answers given in a session's chat get buried under its peer
messages; this file is where the user finds them again. The rule that governs
it is in `CLAUDE.md` § "User questions and answers" (user decisions,
2026-10-14: 「目前我在本session和各个session直接问的问题的回答会被很多消息淹没掉，之后你单独维护一个md文档」;
「排除系统自带askuserquestion tool引发的，一定是user来问的，才记录」).

- **Only questions the user asked.** A question a session put to the user
  (AskUserQuestion, or a question in prose) is not recorded here; its answer
  lives in the ADR, row or rule it decided. Instructions and slash commands
  are not questions either.
- **The question is quoted verbatim; the answer is condensed** to what the
  session concluded (one to four sentences), with a pointer to anything
  longer (a report, ADR, row or commit).
- **Newest entry first, append-only.** A corrected answer is a new entry that
  names the one it corrects.
