WI-0.3 filled this in by reading the code at `a5767d5`. Every `file:line` reference is valid at that commit; unprefixed `:NNN` references point into `docs/design/mdpro-ui-new/proposal-ab.html`. WI-0.4 fills the four screenshot columns.

Shared setup for every row unless the row says otherwise:

- **Theme**: Theme › Light and Theme › Dark in the native menu bar. That menu is the only theme control; no Settings page holds one. In `pnpm dev`, toggle `.theme-light` / `.theme-dark` on `<html>`.
- **Window**: 1200×800 by default, minimum 400×640 (`src-tauri/tauri.conf.json:16-19`). The Size / scale column gives the target size. WI-0.4 appends the backing scale (@1x / @2x), and each before/after pair must match on both.
- **Build**: release-app shots come from `pnpm tauri build`. `pnpm dev` and `pnpm tauri dev` also render the DEV MODE toolbar (`DevToolbar.tsx:28`, `App.tsx:980-984`), so leave it out of any crop meant to match a release shot.
- **Fixture**: `tests/manual-fixtures/wi04-surfaces.md` (added by WI-0.4 in `0c34cf4`). It has H1–H3 headings with one collapsible parent, inline marks (bold, italic, code, strike, highlight), a link and an autolink, inline HTML, a blockquote, bullet, ordered and task lists, a fenced code block, a table, and `![](img/i01.png)`. The menu rows use `d12-table-edges.md` (tables) and `d17-image-heavy.md` (images). Following CLAUDE.md, open a copy from the scratchpad, never the committed file.
- **Focus rings in Tauri** need System Settings › Keyboard › Keyboard navigation turned on, or WKWebView skips buttons when tabbing.
- **Before shots (WI-0.4, 2026-10-05)**: all taken on `mac-mini` (1920×1080, **@1x**) against the release app built from `e121110` (`git diff a5767d5 -- src src-tauri/src` is empty), window-only (`screencapture -l`).
