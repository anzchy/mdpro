# D195 tight and loose lists

Tight bullet list:

- alpha
- beta
- gamma

Tight list with a nested list:

- one
  - one.a
  - one.b
- two

Tight task list:

- [ ] todo
- [x] done
- [ ] later

Tight ordered list:

1. first
2. second
3. third

Loose list (keeps its blank lines):

- loose a

- loose b

- loose c
