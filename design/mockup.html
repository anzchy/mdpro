User journeys

J1 · Open a document and write

  1. Open a file (⌘O, Finder or drag). It opens as a tab in WYSIWYG, the default mode. S1
  2. Type. The tab gets the unsaved dot. S1
  3. ⌘S saves and the dot clears. Auto-save runs on the Settings interval. S5

J2 · Find your way in a long document

  1. The sidebar outline lists the headings; the one in view is highlighted. S1
  2. Click a heading to jump to it; ▾ collapses a branch. S1
  3. Drag the sidebar edge to resize it (180–480 px), or hide it with the first bottom-bar button or ⌘⇧L to write with nothing else on screen. S2

J3 · See the Markdown itself

  1. ⌃2 switches the document to Source mode. S3
  2. ⌃4 switches back to WYSIWYG. S1

J4 · Close a tab without losing work

  1. Click × on a tab with unsaved changes (or ⌘W). S1
  2. The dialog opens with focus on “Keep editing”, so a reflexive Enter keeps the edits (D48). S4

J5 · Make the editor yours

  1. ⌘, opens Settings on General. S6
  2. Pick Editor in the rail; font, size, line height and width apply at once, with no Save button. S6
  3. Close with ×, Esc or a click on the backdrop. S1

J6 · Edit a table

  1. Right-click a table cell. The menu groups insert, move, align, format and delete. S5

J7 · The file changed in another app

  1. Another app saves the open file. The prompt opens with focus on Reload. S7
  2. Ignore (or Esc) keeps the text on screen; Reload replaces it with the disk version. S1

J8 · Get work back after a crash

  1. Launch after a crash or a forced quit. Every unsaved draft is listed with its path and time. S8
  2. Recover opens a draft as a tab; Discard deletes it. S1

J9 · Let an AI client edit a document

  1. Turn on the MCP server in Settings › Integrations. S6
  2. A client asks to write: the prompt names the document and the change, with focus on Reject. Esc or a backdrop click rejects. S9

J10 · Open a file that isn't UTF-8

  1. Open it. mdpro says it can't read it as UTF-8 and offers a UTF-16 retry; focus is on Cancel. S10

J11 · Resize an image

  1. Paste or drop an image into a saved document. S11
  2. Right-click it: 25 / 50 / 75 / 100 %, or Custom… with a number. The width is written back to the Markdown. S11

J12 · Insert a table or a link

  1. ⌘⌥T opens Insert Table: hover the grid or type rows and columns. S12
  2. ⌘K opens Insert Link on the selection. S13
  3. Then edit the table from its menu. S5

J13 · Find and replace in WYSIWYG (target)

  1. ⌘F opens the find bar at the bottom of the editor, above the tabs, pre-filled from the selection; every match is marked and the current one stands out. S14
  2. ⌘G / ⇧⌘G or ↓ / ↑ move between matches; Aa and Whole word narrow them. S14
  3. ⌘H opens the Replace row above Find, with focus in it; Replace or Replace All, then Esc closes and returns to the text. S14
